# PowerBi-project
Interactive Power BI dashboard for real estate sales analysis, featuring revenue tracking, property type insights, regional performance analysis, sales trends, and dynamic filtering for data-driven decision-making.
Real Estate Sales Analytics Dashboard

This project is a Power BI dashboard designed to analyze and visualize real estate sales data. It provides key business insights through interactive visualizations, KPI cards, and dynamic filters.

Features
📊 Total Revenue and Total Sales tracking
🏠 Property Type distribution analysis
🌍 Region-wise performance insights
📈 Sales trend analysis over time
🎯 Average Sales Price monitoring
🔍 Interactive slicers and drill-down capabilities
📌 Clean and user-friendly dashboard design
Technologies Used
Microsoft Power BI
DAX (Data Analysis Expressions)
Data Modeling
Interactive Visualizations
Business Value

The dashboard helps stakeholders identify market trends, evaluate regional performance, monitor sales metrics, and make data-driven decisions in the real estate sector.

Key Metrics
Total Revenue
Total Sales
Average Sales Price
Property Type Distribution
Regional Sales Performance
Time-Based Sales Trends

This project demonstrates skills in data visualization, business intelligence, data modeling, and dashboard development using Power BI.
